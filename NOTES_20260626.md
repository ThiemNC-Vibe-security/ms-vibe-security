## Cách chạy

```bash
# Browser Discovery Agent (default)
cd browser-use-demo/browser-use-demo
.venv/bin/python run_discovery.py --url "https://vc-awg-demo-final-code.vercel.app/" --max-pages 5

# Page Discovery Agent (simple)
.venv/bin/python run_discovery.py --agent page --url "https://uet.vnu.edu.vn/" --max-pages 3

# Gemini API - generate Playwright tests từ discovery JSON
cd gemini-api
npm run generate
```
